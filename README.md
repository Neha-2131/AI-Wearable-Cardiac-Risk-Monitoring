# AI-Based Wearable System for Early Cardiac Risk Monitoring

## Project Overview
This academic design-thinking project explores a wearable system for monitoring health parameters and supporting early awareness of potential cardiac risk indicators.

## Objectives
- Monitor physiological parameters such as heart rate, blood pressure, body temperature, SpO₂, and ECG.
- Explore threshold-based identification of unusual readings.
- Support early risk awareness through wearable technology.

## Proposed Technologies
- Health-monitoring sensors
- C++ (if used in the implementation)
- Sensor data processing

## Project Type
Academic Design Thinking Project

## Disclaimer
This project is for educational purposes and is not intended to diagnose heart attacks or replace professional medical advice.
